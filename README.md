# PROJECT OVERVIEW

The mobile app aims to revolutionize event and hospitality service coordination by creating a seamless connection between customers and verified service providers such as caterers, photographers, event planners, and decorators. Serving as a comprehensive marketplace, the app allows customers to browse, book, and manage event-related services with ease. The app features multi-role registration and verification processes for both customers and providers, ensuring a secure and streamlined experience. Service providers can list their offerings, while customers can request bookings, track progress, and communicate with providers in real time.
With a robust admin panel, administrators can manage user registrations, approve listings, monitor transactions, and oversee content moderation, ensuring smooth operations. The app integrates map functionality for location-based services, secure payment gateways for transactions, and feedback systems for continuous improvement. Designed to be fully responsive and user-friendly, the app ensures scalability and optimal performance across all devices, catering to the growing demand in the event services industry.

# PROJECT PURPOSE

The purpose of this mobile app is to streamline the coordination of event and hospitality services by connecting customers with verified service providers, such as caterers, photographers, and event planners. It aims to simplify the event planning process, allowing users to easily browse, book, and manage services through a user-friendly platform. By providing a secure, role-based registration and verification system, the app ensures reliable interactions between customers and providers. Additionally, the app features real-time communication, secure payment processing, and tracking for services. The admin panel enables seamless management of users, listings, and transactions, ensuring smooth operations. Ultimately, the app seeks to enhance the event planning experience by offering convenience, transparency, and efficient service management for both customers and service providers.


# FEATURE LIST:
## User Management:
- Approve/Reject customer and service provider registrations.
- View and manage profiles of users and service providers.
- Verify provider documents ( certifications, CVs).
- Suspend or delete accounts for policy violations.


## Service Management:
- Approve/Reject service listings and modifications.
- Monitor all active service listings and ensure compliance.
- View detailed service offerings (menus, pricing, specialties) and performance.


## Content Moderation:
- Monitor flagged content (user feedback, reviews, inappropriate listings).
- Respond to and manage any disputes or complaints.
- Edit tooltips, info icons, and guidance text for better user experience.


## Analytics & Reports:
- Access analytics on user activity, bookings, and payments.
- Generate reports for service provider performance, customer satisfaction, and app usage.
- Monitor revenue, transaction history, and payment trends.


## Booking & Payment Monitoring:
- Oversee and approve all payment transactions.
- Track payment statuses (deposit/full payments) and issues.
- Manage refunds and payment disputes.

## Admin Panel Management:
- Full control over app settings and user interface.
- Manage system settings ( categories, service types, payment gateways).
- Access comprehensive dashboards for real-time activity tracking.


## Notifications & Alerts:
- Set up alerts for system-wide notifications ( new bookings, service updates).
- Send announcements or messages to customers and providers about changes.
